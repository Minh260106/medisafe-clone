Ứng dụng Front-end: Quản lý nhắc uống thuốc

Files:
- index.html - giao diện chính
- styles.css - style tách riêng
- app.js - logic & mock data

Chạy: mở `index.html` trong trình duyệt (hoặc serve bằng live server)

Tính năng:
- Dashboard: xem lịch hôm nay, đánh dấu "Đã uống"
- Danh sách thuốc: xem/sửa/xóa
- Thêm thuốc: form đầy đủ + validate cơ bản
- Thống kê: biểu đồ (Chart.js) và lịch sử

Palette gợi ý:
- Primary blue: #2B9ED6
- Accent green: #3FB871
- Muted gray: #6B7280
- Danger: #E65A4A

Gợi ý tiếp theo:
- Muốn mình sẽ bổ sung: toasts, reminder notifications, export/import dữ liệu
